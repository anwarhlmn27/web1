Konsep Pemrosesan Server-Side

Peran PHP dalam Arsitektur Aplikasi Web

  • Server-Side Execution: Kode PHP dieksekusi sepenuhnya di server web, bukan di browser pengguna.
  • Output Dinamis: Mengubah logika aplikasi dan data dari database menjadi struktur dokumen HTML murni sebelum dikirim ke client.
  • Manajemen Sesi & Logika Bisnis: Menangani verifikasi autentikasi user, keamanan form, dan operasi CRUD.
  • Keamanan Source Code: Browser client tidak pernah melihat sintaks logika PHP atau kredensial database.

Alur Data: Request ke Database Response

5 Tahapan Utama Siklus Pemrosesan Web

  1. HTTP Request: User melakukan aksi di browser (misal: kirim form atau akses URL).
  2. Web Server Interception: Web Server (Apache/Nginx) menerima request dan meneruskan file `.php` ke PHP Engine.
  3. PHP Execution & DB Handshake: PHP mengeksekusi script, membuka koneksi PDO ke Port 3306 MySQL.
  4. Database Querying: Database Server mengeksekusi query dan mengembalikan kueri data ke PHP.
  5. HTML Rendering: PHP menyusun data ke template HTML dan mengirimkan hasil akhirnya sebagai HTTP Response ke browser.

Inisialisasi Koneksi PDO Modern

Best Practice Kode Koneksi Database Native

$dsn = "mysql:host=localhost;dbname=db_aplikasi;charset=utf8mb4";
$options = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false,
];

try {
    $pdo = new PDO($dsn, 'root', '', $options);
} catch (PDOException $e) {
    error_log($e->getMessage());
    $db_error = "Terjadi kendala koneksi server database.";
}

Keamanan Prepared Statement

Mengapa Prepared Statement Menangkal SQL Injection?

Parameter Query String Biasa (Rentan) Prepared Statement PDO (Aman)
Proses Query String SQL digabung langsung variabel Struktur SQL di-prepare terpisah dari data
Input Peretas Dianggap sebagai sintaks logika SQL tambahan Diperlakukan murni sebagai teks/literal string
Ketahanan Rentan jebol pola `' OR '1'='1` 100% Aman dari manipulasi logika SQL

Ringkasan & Kesimpulan

Poin Utama Pemrograman Web Berbasis PDO

  • Gunakan PDO (PHP Data Objects) untuk standar pengembangan aplikasi berorientasi objek dan dukungan multi-database.
  • Pastikan selalu mengaktifkan Prepared Statement native (`ATTR_EMULATE_PREPARES => false`) untuk menjamin keamanan dari celah SQL Injection.
  • Pisahkan penanganan Error Log internal teknis server dari pesan kesalahan yang ramah pengguna pada halaman interface (View).
