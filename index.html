📦 Modul 1: Variabel & Scope Control

Mengapa var Ditinggalkan dalam Pemrograman React Native Modern?

var (Deprecated)

  • Scope: Function / Global
  • Bocor keluar dari block { }
  • Rawan memicu bug rendering

let (Mutable)

  • Scope: Block Scope { }
  • Nilai dapat diubah kembali
  • Cocok untuk counter / data temporer

const (Standard)

  • Scope: Block Scope { }
  • Nilai tidak bisa di-reassign
  • Standard komponen, state, & props
💡 Analogi Papan Tulis: var ibarat kardus terbuka di lorong umum. let ibarat laci meja kamar. const ibarat brankas kaca terkunci.

✏️ Latihan Papan Tulis: Human Compiler

Mari analisa eksekusi kode berikut bersama-sama:

// Kasus 1: Block Scope
if (true) {
    var x = "Bocor!";
    let y = "Tergembok!";
}

console.log(x); // Output: ?
console.log(y); // Output: ?
// Kasus 2: Re-assignment
const userRole = "Mahasiswa";
userRole = "Dosen"; 

// Output: ?

🔍 Analisis Jawaban:

  • Kasus 1: x mencetak "Bocor!" karena var mengabaikan block. y menghasilkan ReferenceError.
  • Kasus 2: Menghasilkan TypeError: Assignment to constant variable.

⚡ Modul 2: Transformasi Arrow Function

Menulis fungsi UI yang lebih ringkas dan deklaratif

Sintaks Konvensional (ES5)

function HitungLuas(a, t) {
    return 0.5 * a * t;
}

Arrow Function (ES6+)

const HitungLuas = (a, t) => 0.5 * a * t;

🚀 Keunggulan dalam React Native:

  • Implicit Return: Tidak membutuhkan return jika hanya berupa ekspresi 1 baris.
  • Lexical 'this': Mengikat konteks this secara otomatis untuk event handler tombol.
  • Functional Component Standard: Menjadi standar utama pembuatan komponen UI.

🎨 Template Literals & Destructuring

1. Template Literals (``)

Wajib menggunakan backtick untuk menggabungkan string dan variabel secara bersih:

const nama = "Deden";
const umr = 25;

// ES6 Interpolation
const text = `Nama: ${nama}, Umur: ${umr}`;

2. Object Destructuring

Mengekstrak properti objek langsung ke dalam variabel terpisah:

const user = { name: "Deden", role: "Mhs" };

// Destructuring langsung
const { name, role } = user;

🌉 Bridging to React Native: Props & State

Penerapan langsung ES6 Destructuring pada Komponen Mobile

❌ Tanpa Destructuring

const UserCard = (props) => {
  return (
    <Text>
      {props.nama} - {props.role}
    </Text>
  );
};

✅ Standar React Native (Destructuring)

const UserCard = ({ nama, role }) => {
  return (
    <Text>
      {nama} - {role}
    </Text>
  );
};
📌 Destructuring React Hooks: const [isLogin, setIsLogin] = useState(false);

🔀 Logic & Flow Control untuk Tampilan UI

1. Ternary Operator (If-Else)

Sangat ideal untuk memilih 2 tampilan UI berdasarkan kondisi:

// kondisi ? true : false
<Text>
  {isStudent ? "Aktif" : "Alumni"}
</Text>

2. Logical AND (&&)

Renders elemen UI hanya jika kondisi terpenuhi:

// Jika isLogin true, tampilkan komponen
{isLogin && <Dashboard />}

🗺️ Array Mapping untuk List UI

Di React Native, kita tidak memakai for loop untuk merender daftar data

const hobbies = ["Coding", "Gaming", "Reading"];

return (
  <View>
    {hobbies.map((item, index) => (
      <Text key={index}>
        Hobi {index + 1}: {item}
      </Text>
    ))}
  </View>
);

🔍 Bedah Kode React Native (App.js)

import { Text, View } from 'react-native';

export default function App() {
  let alas = 10;
  let tinggi = 5;
  const setengah = 0.5;

  const hitungLuas = (a, t) => setengah * a * t;
  let luas = hitungLuas(alas, tinggi);

  return (
    <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
      <Text>
        {`Luas segitiga alas ${alas} & tinggi ${tinggi} adalah ${luas}`}
      </Text>
    </View>
  );
}
